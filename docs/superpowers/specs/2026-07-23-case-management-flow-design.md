# Case Management Flow Design

## Goal

사례 생성과 편집을 사례 관리 화면에 모으고, 작업 전·후 사진 업로드를 분리하며, 고객 확대 사진에 단계 배지를 표시한다.

## Approved Design

- 대시보드·관리자 내비게이션의 별도 `새 사례` 링크를 제거한다.
- 사례 관리 헤더에 `사례 추가` 버튼을 두고 목록의 `편집` 버튼을 유지한다.
- 사례 편집 화면은 작업 전과 작업 후의 독립 드롭존을 제공한다.
- 각 드롭존은 단계 값을 자동 지정하며 공통 검증·미리보기·Storage 비활성 정책을 재사용한다.
- 고객 빠른 상세보기와 라이트박스 우측 상단에 현재 사진이 `before` 또는 `after`일 때만 한국어 배지를 표시한다.

## Error and Accessibility Behavior

- 기존 업로드 제한과 오류 다이얼로그를 공유한다.
- 드롭존 입력 라벨과 테스트 ID는 단계별로 유일하다.
- 배지는 고대비 텍스트를 사용하고 버튼 조작 영역을 침범하지 않는다.

## Verification

관리자 진입, 단계별 업로드, 라이트박스 배지를 컴포넌트 테스트에서 검증하고 관련 Playwright와 전체 품질 명령을 실행한다.
