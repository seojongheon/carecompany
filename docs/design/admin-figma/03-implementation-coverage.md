## 구현 원칙

- 새 정보 설계는 기존 데이터·행동을 모두 포함한다. 기존 화면의 내용이 디자인에서 축약된 경우 상세 그룹/탭/펼침 영역에 추가한다.
- Figma 예시 수치·사람·문구는 실제 운영값으로 대체한다. 긴 폼·표는 내용만큼 확장한다.
- 디자인과 달리 업무상 필요한 상태·경고·복구 버튼은 숨기지 않는다.
- 폼의 필드를 다른 섹션으로 옮길 때 저장·검증·충돌 계약을 변경하지 않는다.
