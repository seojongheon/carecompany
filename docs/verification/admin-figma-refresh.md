# 관리자 Figma UI 적용 검증 · 2026-10-23

## 범위와 기능 보존

승인된 [Figma](https://www.figma.com/design/rdCv6zt7qIe1kWIyBd0Wh0)의 Desktop/Mobile 디자인을 실제 운영 데이터에 연결했다. 고객 홈의 브랜드 색상, 폰트 스택, 둥근 모서리와 버튼 체계를 공유하고 관리자 전용 CSS로 레이아웃을 정리했다.

기존 009 운영 계약은 변경하지 않았다. 구현 계약은 `specs/010-admin-figma-refresh/`, 기능별 대조 근거는 `docs/design/admin-figma/03-implementation-coverage.md`에 있다. 9개 메뉴와 상세 영역을 먼저 대조한 뒤, 디자인에 축약된 다음 내용을 유지했다.

- 문의: 접수 경로·기간·정렬·미읽음·회원 조건, 수동 등록, 내부 메모·상태·담당자·이력.
- 사례: 태그 관리, 작업일·표시 시기·SEO, 모든 사진/영상 관리, 공개 검토·초안 폐기·이력·삭제함 복구.
- 콘텐츠: 모든 기존 문서 필드와 반복 항목, 문서별 저장·게시·비교·미리보기·복원, 공지 검색·페이지.
- 미디어·회원·설정·통계: 파일 참조/삭제 차단/재시도, 역할·활성 변경 사유, 별도 역할 기록, 캠페인 통계.

## 변경 결과

밝은 240px 사이드바와 72px 상단바, 그룹 메뉴, 공통 제목·카드·탭을 적용했다. 대시보드는 실제 문의·업무·방문·콘텐츠 요약으로 구성했다. 문의는 목록/고급 필터/상담 보조패널, 사례와 문서는 편집 본문/게시 보조패널로 정리했다. 모바일에서는 메뉴 시트, 카드 목록, 접이식 필터, 문서 하단 저장·게시 동작을 제공한다.

실제 데이터가 없는 영역에는 빈 상태나 수집 전 상태를 표시한다. Figma의 예시 고객·사례·통계 수치를 데이터로 추가하지 않았다.

실제 방문한 경로는 대시보드, 문의 목록, 사례 목록/신규/기존 편집, 서비스/서비스 편집, 사이트 홈/소개/과정/FAQ/정책/공지, 미디어, 회원 목록/상세, 통계, 기본/알림/활동/역할 설정이다. 읽기용 로그인 링크를 생성했으며 이메일은 발송하지 않았다. 테스트 후 해당 세션만 종료했다. 자격증명과 회원 식별자는 이 문서에 저장하지 않았다.

회귀 테스트는 모바일 메뉴 닫기, 필터 값 보존, 수동 등록 펼침/첫 입력 포커스, 문의 분류와 필터 보존, 사례 섹션 이동/입력 유지/레이블 접근성, 문서 필드 누락 방지/탐색 보호/숨김 공지 상태를 추가했다. 각 행동 수정은 실패를 확인한 뒤 구현했다.

## 적용 경계

- 위 구현 검증 시점에는 UI를 로컬 프로덕션 빌드까지 확인했다. 이후 사용자 요청에 따라 아래 운영 배포 검증을 완료했다.
- Supabase 권한 보완 마이그레이션은 연결된 운영 DB에 적용했다. 데이터 34개 테이블 및 버킷 5개 설정 보존과 실제 역할 검사 197개 결과는 `supabase-2026-10-23.md`에 기록했다.
- 이번 브라우저 검증은 운영 콘텐츠·회원 역할·문의 데이터를 변경하지 않았다. 문의 상세는 기존 컴포넌트/DB 회귀 검사로 확인했으며 운영 문의가 없어 실제 상세 경로를 열지는 않았다.
- 실제 파일 업로드·공개 게시·성공 문의 접수의 운영 쓰기 E2E는 이번 UI 점검에서 재실행하지 않았다. 기존 정책의 미게시 상태와 Storage 설정은 그대로 유지했다.

스크린샷과 로컬 실행 근거는 `.cache/admin-refresh/`에 보관한다. 운영 행이 포함될 수 있으므로 이미지와 임시 인증 스크립트는 저장소에 추가하지 않는다.
