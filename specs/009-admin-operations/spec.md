# 관리자 운영 시스템 통합·확장

Status: Approved by user on 2026-10-19. Source: approved implementation plan in this chat.

## Intent and ownership
Spec Kit owns this contract; Superpowers owns TDD, implementation, review and verification. This supersedes incomplete site-content requirements in 002 and extends 003/004/006/007/008 without rewriting those specifications. Existing public URLs, accounts, case IDs and storage paths survive. Existing login redirects to `/` remain. No payments, reservations, chat, automatic quotes, external analytics integration, outbound customer messaging, new service taxonomy or fine-grained staff roles.

## US1 — Shared operations shell (P1)
Nine menus: dashboard, inquiries, cases, services/pricing, site content, media, users/roles, visitor analytics, settings. One shared desktop/mobile navigation definition with active route, breadcrumbs, notification inbox, account/logout/public site link. Server and DB validate active admin on every protected operation; super_admin alone manages users, settings, policy edits and global audit. Tables paginate at 20, URL-backed search/filter/sort. Show loading/empty/error/retry states, never failed queries as zero.

## US2 — Independent content publishing (P1)
Document units: home, about, process, policy, settings, each canonical service, pricing collection, FAQ collection, individual announcement. Draft save, version conflict, desktop/mobile preview, change comparison, validation, atomic publish, history and restore-to-draft. Services keep four canonical keys/URLs. Prices support multiple entries/service, label/unit/range/conditions/inclusions/exclusions/visibility/order, no historical case cost. Home includes hero/CTA/sections/recommendations; about includes image/values/CTA; process includes ordered steps/images; notices include title/body/images/pinning/status; FAQs have common/service/pricing categories; policy includes effective date, inquiry consent and review acknowledgement. Public home/services/pricing/about/process/privacy/footer/metadata read published data only. Admin cannot edit policy/settings. No arbitrary page builder. Current `/admin/site` retained. Existing whole-site write RPCs must no longer bypass document boundary.

## US3 — Published cases stay online during edits (P1)
Separate case revision draft containing body, media/video/tag manifest and privacy checklist. Current published projection is unchanged until atomic publish. Existing 20 files/batch, 69 photos/case, 3 YouTube videos/case. Adding/replacing public photos invalidates privacy review. Optimistic revision checks prevent lost updates. Search title/region, filter service/status/dates, sort updated/published, distinguish published with draft. Editor includes all existing fields, SEO preview, image alt/caption/stage/cover/public/sort, videos, tags, featured order, save/error/conflict state. Separate discard draft, unpublish, trash, restore trash as private; no permanent case delete. History restores as draft. Existing published projection writes restricted to trusted functions. Backfill existing cases without changing URLs/status/files.

## US4 — Media library (P2)
Site images/case photos/failed uploads/cleanup tabs; thumbnail/name/size/type/created/owner/usage. Site upload/select/reuse/replace and use-specific alt/focal metadata. Case edits link to case editor. Original/reviewed distinction. In-use assets cannot be removed if referenced by draft/published/history; unused deletion has confirmation. Durable server cleanup jobs with retry; inquiry attachments excluded from library and public reuse. Never delete current published files merely because draft removes them.

## US5 — Inquiries and in-app notifications (P1)
Public inquiry entry replaces inert estimate button. Guest or active customer submits name/phone/service/region/message/consent, optional 5 JPEG/PNG/WebP photos max 10MiB each. Server limits, safe image validation, rate limiting and idempotency; dedicated private attachments. Success receipt number, no guest lookup by number. Member linkage derives authenticated user only, never by matching email/phone. Account shows own content/date/customer-safe status, never notes/assignee/audit. Manual staff entry records phone/Kakao origin. List search receipt/name/phone/body; status/service/date/assignee/source filters, default newest, 20/page, unread separate from status. Detail assignment, new/consulting/on_hold/completed/spam, private notes/history, tel/copy, previous/next. Reopen completed, restore spam. In-app notices for new inquiry to active staff, assignment to assignee, processing failures; configurable recipients. Per-user read/all-read, target links, 60s refresh while visible, event deduplication. External notification failure never rolls back inquiry.

## US6 — Users/settings/audit (P1)
Super-admin user list/search/role/active/date filters and account detail with linked inquiries; promote existing customer to admin/revoke, suspend/reactivate with reason and confirmation, immutable super-admin web role and last master protection. Suspension applies new login and existing protected sessions. No password inspection, hard delete or invitation emails. Settings: business/logo/contact/address/hours/regions/email/social/Kakao, SEO default title/description/share image, header/footer/CTA shared. Policy edit/publish master-only. Audit immutable, query by date/actor/target/action; summarize case/content/prices/settings/inquiries/media/account changes without secrets or customer body/photos. Reuse role audit. External email/SMS/Kakao configuration records recipients/event types/template reference/provider status/outbox/attempt interface; no provider chosen, no live send, no enable without connected adapter, no queued historical backlog. Operators only, no marketing or customer messages.

## US7 — Consented visitor analytics (P2)
Consent before collection; withdrawal stops collection and removes anonymous browser ID. Anonymous browser visitors, visits after 30m idle, deduplicated page-view events on actual route change. Never link account ID or store email/phone/inquiry text/raw IP/full URL query. Allowlisted path/campaigns only, external referrer domain, device mobile/desktop/tablet. Exclude admin/preview/auth/account and known bots; exclude authenticated staff. Asia/Seoul aggregation, today/7d/30d/custom last90d; raw data retention90d. Show consent-based coverage and not-started state. Popular pages/public cases, sources/devices. Collector abstraction permits later external adapters but no third-party scripts now. No revenue/conversion analytics.

## US8 — Operational dashboard (P2)
Real new/open/mine/unassigned inquiry counts; published/private/cases with draft/pending documents; today visits/visitors/views and 7day trend; recent inquiry/case/content activity; failed upload/cleanup/operation alerts. Cards link to matching filters. No mock copy, fabricated counts or creation CTA duplication (create in cases only).
