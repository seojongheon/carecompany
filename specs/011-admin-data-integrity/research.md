# 조사와 결정
- 17개 migration 일치, 테이블/제약/정책/함수/인덱스/grants 일치. services.slug 기본값만 로컬 최초 migration에 부정확하게 존재한다.
- 실제 문서19·이력8, 사례 초안52·이력10의 SQL 검증 통과. 사례 revision/id/status 불일치0, private 초안 누락0, 서비스/가격 투영 불일치0, 미디어 등록 누락/객체 누락0, 회원/Auth 연결 누락0.
- settings의 확장 필드는 실제 JSON에 누락되어 있으며 현재 편집기는 기본값 병합으로만 동작한다. 기존 키가 우선하는 누락키 보충을 선택한다. 실제 연락처/사업자정보 생성은 제외한다.
- pricing 최초 이관은 draft.priceItems 없음을 빈 배열로 바꾸고 published는 price_items에서 읽었다. 편집 이력 없는 대상만 복구한다. 모든 빈 초안 덮어쓰기와 전체 재시드는 거부한다.
- 이전 형식 가격ID는 publish 시 테이블에만 UUID로 변환되어 공개 JSON과 차이가 날 수 있다. 게시 트랜잭션 안에서 동일 ID로 정규화한다. 프런트엔드만 UUID를 강제하면 이력 복원/RPC를 해결하지 못한다.
- 정책은 미검토/미게시이므로 문의 접수는 현재 차단된 정상 운영 조건이다. 정책 대신 작성·검토 표시나 임의 게시를 하지 않는다.
